# DWG Normalizer

Приводит шрифты и размерные стили в чертежах AutoCAD к единому стандарту.
Работает с DWG любой версии: чертёж конвертируется через AutoCAD, который уже
установлен на компьютере, и сохраняется в том же формате, в каком был.

## Зачем

Разные конструкторы и архитекторы оформляют чертежи по-своему. В одном файле легко
набирается полтора десятка текстовых стилей, жирность и курсив, зашитые прямо в строки
MTEXT, и несколько размерных стилей с локальными переопределениями. Инструмент сводит
всё это к одному профилю (например, ГОСТ 2.304).

## Установка (для пользователей)

1. Скачать `DWG-Normalizer-Setup-*.exe` со страницы **Releases** этого репозитория.
2. Запустить. Windows один раз покажет синее окно SmartScreen, потому что у
   установщика нет цифровой подписи: «Подробнее» → «Выполнить в любом случае».
3. «Далее» → «Установить». На рабочем столе появится ярлык.

Права администратора не нужны, Python ставить не нужно. Нужен только установленный
**AutoCAD 2013 или новее** — любой версии, программа найдёт его сама.

Чертёж можно перетащить прямо на ярлык: программа откроется с уже выбранным файлом.

## Как пользоваться

1. Выбрать чертёж (или папку с чертежами и включить пакетный режим).
2. «Проверить» — покажет, что в чертеже сейчас, ничего не меняя.
3. «Нормализовать» — результат пишется рядом, в файл `имя_normalized.dwg`.
   Оригинал никогда не перезаписывается.

## Что делает

**Текст**
- ставит единый шрифт всем текстовым стилям и приводит к нему семейство шрифта
  в служебных данных стиля (XDATA), снимая там жирный и курсив;
- inline-код шрифта в MTEXT `\f...;` (шрифт + жирность `b1` + курсив `i1`) вырезает,
  если стиль надписи сам даёт целевой шрифт. На остальных стилях (например, SHX,
  которые не конвертируются) код переписывается на целевой шрифт, чтобы надпись
  не «провалилась» в шрифт стиля;
- вырезает `\Q` (наклон);
- обрабатывает модель, листы и именованные блоки (штампы, рамки).

**Размеры**
- переводит все размеры на один эталонный стиль;
- снимает локальные переопределения с отдельных размеров.

Не трогает `\L` (подчёркивание), `\P` (перенос строки), `\pxqc` (выравнивание) и по
умолчанию `\W` (ширину): это содержимое, а не оформление.

## Как работает с DWG

DWG — закрытый формат, читать его напрямую нельзя. Программа использует консольную
версию AutoCAD (`accoreconsole.exe`), которая входит в любой AutoCAD с 2013 года:

1. AutoCAD выгружает чертёж в DXF (команда `DXFOUT`);
2. правки вносит `ezdxf`;
3. AutoCAD сохраняет результат обратно в DWG (`SAVEAS`).

Формат сохраняется исходный: файл из AutoCAD 2013 останется в формате 2013 и
откроется у коллеги со старой версией. Если на компьютере стоит AutoCAD старее, чем
формат чертежа, программа скажет об этом прямо, а не испортит файл.

Если AutoCAD не найден, используется ODA File Converter, когда он установлен.
Учтите: без членства в ODA он разрешён только для некоммерческого использования.

## Профиль стандарта

Лежит рядом с программой, правится блокнотом, пересборка не нужна.

```jsonc
{
  "acad_path": null,            // путь к accoreconsole.exe; null = найти сам
  "dwg_formats": {},            // дополнения таблицы форматов DWG, если выйдет новый
  "text": {
    "font": "isocpeur.ttf",     // целевой шрифт: TTF или SHX (cs_gost2304.shx)
    "font_family": "ISOCPEUR",  // семейство TTF-шрифта; для SHX-цели ставится null
    "width": null,              // null = не трогать, или число (0.85)
    "oblique": null,            // null = не трогать, или угол (15.0)
    "skip_styles": [],          // стили-исключения
    "convert_shx": false,       // true = переводить и SHX-стили на TTF
    "strip_inline_font": true,
    "strip_inline_width": false,
    "process_blocks": true
  },
  "dimensions": {
    "enabled": true,
    "target_style": null,       // null = самый используемый стиль в чертеже
    "clear_overrides": true,
    "text_style": null          // текстовый стиль для подписей размеров
  }
}
```

Под разные стандарты делаются копии этого файла: программа подхватывает все `*.json`
из своей папки и показывает их списком под именем из поля `name`. При запуске выбран
основной профиль — всё приводится к ISOCPEUR, включая стили на SHX-шрифтах.

## Оговорки

- **Основной профиль переводит на ISOCPEUR и SHX-стили** (`convert_shx: true`). Если в
  каком-то чертеже после этого поедут спецсимволы (Ø, °, ±), обработайте его запасным
  профилем «ISOCPEUR, SHX-стили не трогать».
- **Размеры хранят отрисованную геометрию** в анонимных блоках `*D1`, `*D2`… Если после
  смены стиля размеры выглядят по-старому, выполните в AutoCAD `REGEN`.
- **Список «не используются» в диагностике не повод удалять стили**: стили из блоков
  могут туда попадать, хотя реально нужны. Поэтому автоудаления стилей нет.
- Сначала «Проверить», потом нормализация. Результат смотрите в AutoCAD.

## Разработка

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python gui.py
```

Из командной строки:

```powershell
python dwg_normalizer.py чертеж.dwg                        # нормализовать
python dwg_normalizer.py чертеж.dwg --scan                 # только диагностика
python dwg_normalizer.py чертеж.dwg -p profile_gost.json   # со своим профилем
python dwg_normalizer.py C:\чертежи --batch                # вся папка
python inspect_text.py чертеж.dwg "фрагмент"               # чем задан шрифт надписи
```

| Файл | Назначение |
|---|---|
| `dwg_normalizer.py` | Ядро: конвертация, диагностика, нормализация; работает и как CLI |
| `gui.py` | Интерфейс |
| `inspect_text.py` | Диагностика одной надписи: где лежит и что задаёт её шрифт |
| `build.py` | Сборка в exe через PyInstaller |
| `installer.iss` | Установщик (Inno Setup) |
| `profile_gost.json` | Основной профиль: всё к ISOCPEUR, включая SHX-стили |
| `profile_gost_safe.json` | Запасной: ISOCPEUR только для TTF-стилей, SHX не трогает |
| `profile_gost_shx.json` | Запасной: всё к ГОСТ-шрифту `cs_gost2304.shx` |
