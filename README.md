# DWG Normalizer

Приводит шрифты и размерные стили в чертежах AutoCAD (DWG/DXF) к единому стандарту.
Работает с файлами напрямую: AutoCAD не нужен, поддерживаются чертежи версий 2000–2027.

## Зачем

Разные конструкторы и архитекторы оформляют чертежи по-своему. В одном файле легко
набирается полтора десятка текстовых стилей, жирность и курсив, зашитые прямо в строки
MTEXT, и несколько размерных стилей с локальными переопределениями. Инструмент сводит
всё это к одному профилю (например, ГОСТ 2.304).

## Файлы

| Файл | Назначение |
|---|---|
| `dwg_normalizer.py` | Ядро: диагностика и нормализация; работает и как CLI |
| `gui.py` | Простой интерфейс (tkinter) |
| `profile_gost.json` | Профиль стандарта: шрифт, правила чистки, размеры |
| `requirements.txt` | Зависимости Python |

## Установка (Windows)

Нужны Python 3.13 и [ODA File Converter](https://www.opendesign.com/guestfiles/oda_file_converter)
(бесплатный, через него читаются и пишутся DWG). Затем в папке проекта:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

ODA File Converter ищется автоматически в `C:\Program Files\ODA\` (любая версия).
Если он установлен в другое место, укажи путь к `ODAFileConverter.exe` в профиле,
ключ `oda_path`.

## Запуск

С интерфейсом:

```powershell
python gui.py
```

Из командной строки:

```powershell
python dwg_normalizer.py чертеж.dwg                        # нормализовать
python dwg_normalizer.py чертеж.dwg --scan                 # только диагностика
python dwg_normalizer.py чертеж.dwg -p profile_gost.json   # со своим профилем
python dwg_normalizer.py C:\чертежи --batch                # вся папка
```

Оригинал никогда не перезаписывается: результат пишется в `имя_normalized.dwg`.

## Что делает

**Текст**
- ставит единый шрифт всем текстовым стилям;
- вырезает из MTEXT inline-коды `\f...;` (шрифт + жирность `b1` + курсив `i1`) и `\Q` (наклон);
- обрабатывает модель, листы и именованные блоки (штампы, рамки).

**Размеры**
- переводит все размеры на один эталонный стиль;
- снимает локальные переопределения с отдельных размеров.

Не трогает `\L` (подчёркивание), `\P` (перенос строки), `\pxqc` (выравнивание) и по
умолчанию `\W` (ширину): это содержимое, а не оформление.

## Профиль

```jsonc
{
  "oda_path": null,             // null = найти ODA автоматически
  "text": {
    "font": "isocpeur.ttf",     // целевой шрифт
    "width": null,              // null = не трогать, или число (0.85)
    "oblique": null,            // null = не трогать, или угол (15.0)
    "skip_styles": [],          // стили-исключения
    "convert_shx": false,       // true = переводить и SHX-стили на TTF
    "strip_inline_font": true,
    "strip_inline_width": false,
    "process_blocks": true
  },
  "dimensions": {
    "target_style": null,       // null = самый используемый стиль в чертеже
    "clear_overrides": true,
    "text_style": null          // текстовый стиль для подписей размеров
  }
}
```

Под разные стандарты делаются копии этого файла; GUI подхватывает все `*.json` из своей папки.

## Оговорки

- **SHX-шрифты по умолчанию пропускаются**: замена SHX на TTF может сломать спецсимволы
  (диаметр, градус). Включается через `convert_shx`.
- **Размеры хранят отрисованную геометрию** в анонимных блоках `*D1`, `*D2`… Если после
  смены стиля размеры выглядят по-старому, выполни в AutoCAD `REGEN`.
- **Список «не используются» в диагностике не повод удалять стили**: стили из блоков
  могут туда попадать, хотя реально нужны. Поэтому автоудаления стилей нет.
- Сначала `--scan`, потом нормализация. Результат проверяй в AutoCAD.
